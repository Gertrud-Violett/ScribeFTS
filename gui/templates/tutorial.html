Tutorial & Setup Guide

Everything you need to get started with ScribeFTS.

1. Basic Usage

Adding files to your library

There are two ways to add PDFs:

A
Passive scanning — Copy or move PDFs into any of your configured scan directories, then click Refresh in the navigation bar. ScribeFTS will detect the new files, deduplicate by content hash, and index them automatically.
B
Manual upload — Click Upload in the navigation bar. A popup appears with two input options:
  • File — select a PDF from your computer using the file picker.
  • Direct PDF URL — paste any direct link to a PDF (e.g. from arXiv).
Set the Save to directory field by typing a path or clicking Browse… to navigate your filesystem visually (single-click to highlight a folder, double-click to enter it). If the destination is outside your configured scan directories, a warning will appear — you can proceed anyway, but the file will not be indexed automatically until you add that path to your scan directories.

Using the Discovery Scout

1
Go to Discover in the navigation bar.
2
Type keywords into the search bar (e.g. transformer attention mechanism). Results are fetched live from arXiv and show title, authors, year, and a short abstract.
3
Click Download & Register on any result. A dialog appears — choose the save directory (using Browse… if needed) and click Download. The PDF is fetched, saved, and indexed automatically.
If the save directory is outside your scan directories, the same two-step warning flow applies as with manual upload.

Searching your library

The search bar in the Library view supports two modes:

  • Metadata search — Searches filenames and all indexed metadata fields (title, authors, genre, keywords…).
  • Full-text search — Uses the FTS5 index to search inside the full body text of indexed PDFs. Toggle the radio button next to the search bar.

Editing metadata

Click any entry title to open the detail view, then click Edit. You can also click the pencil icon directly from the library list to open an inline edit modal.

2. AI Metadata Extraction (Gemini)

ScribeFTS can automatically extract the title, authors, year, and keywords from new PDFs by reading the first pages of each document and sending the text to the Gemini API.

How to enable

1
Get a free API key from Google AI Studio (aistudio.google.com) — no billing required for the free tier.
2
Click API in the navigation bar, then select the API tab (the right-hand tab).
3
Tick Enable AI Assist, select Google Gemini as provider, paste your key, and set the model (e.g. gemini-1.5-flash). Click Save.
4
Click Refresh. New files will have metadata suggested automatically.

Draft vs. commit

Extracted values are staged as drafts before being written to the database:

  • Fields extracted with confidence ≥ the auto-commit threshold (default 0.8) are committed immediately.
  • Lower-confidence fields appear as pending drafts — visible on the entry detail page — for your review before committing.

Use Commit All on the Library page to accept all pending drafts at once.

OpenAI-compatible models also work — set Provider to OpenAI-compatible and supply your endpoint URL and key. This is useful for self-hosted models (Ollama, LocalAI, etc.).
The Config tab (left-hand tab under API) is where you manage scan directories, file extensions, and custom metadata fields.

3. Google Drive Sync & NotebookLM Bridge

You can sync your ScribeFTS library to Google Drive — and then point NotebookLM directly at that folder — without any API keys or OAuth flows. The trick is to use Google Drive for Desktop, which mounts your Drive as a local folder on your PC.

Step-by-step

1
Download and install Google Drive for Desktop from google.com/drive/download. Sign in with your Google account.
2
After installation, a virtual drive appears on your system (e.g. G:\My Drive\ on Windows). Any folder you place inside it is automatically synced to the cloud.
3
In ScribeFTS, go to Workspace and use Move Workspace to relocate your workspace to a folder inside the Drive path — for example:
G:\My Drive\scribeFTS-library\data
4
Update your scan directory (in Config) to point to where your PDFs live under the Drive folder — for example:
G:\My Drive\scribeFTS-library\papers
5
ScribeFTS writes all database files and new PDFs into that folder. Drive for Desktop syncs them to the cloud silently in the background.
6
In NotebookLM (notebooklm.google.com), create a new notebook, click Add Source → Google Drive, and select your synced papers folder. NotebookLM will index all PDFs as sources and allow you to query them with AI.
No OAuth, no API keys. Google Drive for Desktop handles authentication at the OS level. ScribeFTS only reads and writes to the local filesystem — it never contacts Google's servers directly.
Sync delay: Drive for Desktop syncs in the background. After adding new papers, allow a minute or two before they appear in your Google Drive and NotebookLM.
